# 👥 User Stories (LaundroTwin Project)

**Document Purpose:** This document captures the functional needs from the perspective of different users (Owner, Manager, Technician, Customer, Marketer). It is used to drive the development of features and maintain the Requirements Traceability Matrix (RTM).

| ID | Category | Role | I want to... | So that... | Data / Scope | Related Reqs | Priority | Acceptance Criteria |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **US-01** | Gas Management | Branch Manager | Receive a LINE message when the system estimates low gas. | I can order gas before the dryer service is disrupted. | `pressure`, `temperature`, `dryer state`, alert thresholds | R05, R06 | **MVP** | Triggered condition sends a unique (idempotent) message containing the branch, sensor, and timestamp. |
| **US-02** | Business Intelligence | Owner | View machine status, remaining time, and temperature for my authorized branches. | I can monitor the storefront situation without relying on CCTV. | Verified register map, latest normalized telemetry | R02, R04 | **MVP** | Dashboard updates with accurate latest telemetry within 2 seconds at p95 latency. |
| **US-03** | Business Intelligence | Branch Manager | Receive an alert when the estimated coin box volume reaches the threshold, and log the reset action. | I can collect coins before the machine stops accepting payments. | Calibrated cash/coin events, `coinbox_open` mapping | R05, R07 | **MVP** | A reset audit record is created ONLY after a mapped `coinbox_open` event is received. |
| **US-04** | Business Intelligence | Owner | View total revenue, cycle counts, and utilization rates filtered by branch and time period. | I can make operational decisions based on traceable data. | Normalized paid/cycle events, branch & time filters | R03, R04 | **MVP** | Selected dashboard totals must be traceable to the source events for that branch/timeframe. |
| **US-05** | AI Assistance | Owner | Ask for a scoped Executive Summary (e.g., MoM revenue by branch). | I gain business insights without exposing unauthorized data. | Allow-listed analytics functions, RBAC context, audit log | R04, R08 | **MVP** | Assistant strictly uses specified analytics functions and CANNOT execute arbitrary SQL. |
| **US-06** | AI Assistance | Marketer | Receive recommended off-peak periods for promotions. | I can plan promotions based on historical demand instead of guessing. | Usage time-series, program selection by branch | R09 | *Phase 2* | Recommendations clearly specify branch, timeframe, metric, and the rules used to determine low usage. |
| **US-07** | Customer Experience | Customer | See which machines are available and their remaining time. | I can plan my visit without creating an account. | Sanitized public machine-status API | R11 | *Phase 2* | Endpoint explicitly excludes revenue data, raw telemetry, and cross-branch data. |
| **US-08** | Maintenance | Technician | Receive an alert specifying the machine ID and evidence when a rule-based anomaly is detected. | I can triage and resolve issues faster to reduce downtime. | `state`, `temperature`, error codes, alert rules | R05, R10 | **MVP** | Alert specifies machine ID, rule version, trigger values, and event timestamp. |
| **US-09** | System Architecture | Owner | Switch views between the branches I am authorized to manage. | I can manage multiple laundromats through a single account. | Tenant-aware database queries, branch assignment | R04 | **MVP** | ALL API responses are strictly restricted by the authorized `branch_id`. |
| **US-10** | System Reliability | Owner | Use a dashboard that meets clearly defined performance targets. | I know the exact service level the prototype can prove. | Telemetry pipeline, dashboard API, test workload | R01, R02 | **MVP** | Test report verifies p95 telemetry-to-dashboard latency and reconnect behaviors. |
| **US-11** | Data Privacy | Owner | Assign roles so branch staff can ONLY view data for their specific branch. | I can protect franchise business data. | RBAC roles, JWT/session, branch assignments | R04 | **MVP** | Automated tests confirm that unauthorized cross-branch API requests are explicitly denied. |
